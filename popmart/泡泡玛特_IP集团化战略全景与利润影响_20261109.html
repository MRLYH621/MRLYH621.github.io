1｜是什么：不是「多元化」，是同一份 IP 资产的多次变现

王宁定义：全球化 = 已验证商业模式的扩张（空间维度）；集团化 = 以 IP 为核心的产业化（变现维度）。IPO 时即定下这两大战略。2024 年报把集团业务重组为「消费品、服务与体验、数字娱乐」三大板块；2026 Q3 电话会进一步收窄成两大方向：① 用电影/乐园增厚 IP 厚度与情感连接；② 拓展适配 IP 的更多品类。

2｜现状：报表上是「费用项 + 期权」，还不是「利润项」

2025 年自主产品收入 367.88 亿（99.1%），2026H1 为 170.61 亿（99.3%）；IP 授权及其他服务收入 2025 仅 0.71 亿。乐园收入从未单列，被合并在中国区「批发及其他」9.08 亿里（该项还含批发）。已跑通的是「品类扩张」（毛绒占比 21.7%→50.4%），未跑通的是「业态扩张」：游戏《梦想家园》停运，王宁自评电影与游戏「不太成功」。

3｜对利润：短期不该让集团化背锅，中期看引流，长期才决定估值范式

2026H1 经营利润率 39.2%（同比 −4.4pct）主要来自 汇兑等「其他亏损净额」6.89 亿；剔除其他收入/损益后的核心经营利润率为 41.4% vs 上年同期 41.8%，基本持平，销售费用率 22.9% vs 23.0% 也没上升。集团化当前的真实成本在资本开支、租赁与组织复杂度（H1 使用权资产 +8.1 亿），不在当期费用率。真正的利润弹性要等体验/授权收入占比突破 5%。

4｜对布局：从「一维铺店」变成「IP × 品类 × 业态」三维，但风险尚未真正分散

单 IP 集中度已从 38.1% 降到 26.0%，但毛绒品类占比反而升到约 57%；Q3 整体收益同比 −45%~−50%，新业态规模太小，完全无法对冲主业波动。集团化目前的作用是把「一次性交易」变成「日常触点」，而不是造第二个收入支柱。

5｜判断：2028 年前集团化难以贡献 >10% 经营利润；估值重估需要两个硬信号

① 财报单列体验/授权收入且占比 >5%；② 内容或乐园能验证 IP 寿命延长（老 IP 复购、非爆款 IP 稳定变现）。在此之前，市场仍会按「爆款周期股」而非「IP 平台」定价。管理层明确「短期内不会大幅增加内容预算」，说明公司自己也选择了低成本试错、不押注重资产内容。

一、什么是「围绕 IP 的集团化」

定义、结构、与全球化的分工

资产层｜IP 是唯一的「母资产」

签约艺术家 → 孵化/运营 IP → 商标与著作权沉淀 → 会员与情感资产。官网早期表述为「艺术家挖掘、IP 孵化运营、消费者触达、潮玩文化推广、关联产业投资整合」五个领域的全产业链平台；集团化是这套平台的升级版。

艺术家签约（保底+分成）IP 矩阵：17 个 IP 年收入过亿（2025）1 亿+ 会员 / 复购约 51.6%著作权 1955 项（工商口径）

变现层｜同一个 IP，卖 N 次：三大板块

2024 年报原文：「重新梳理了集团业务板块：消费品、服务与体验、数字娱乐……用 IP 连接起全球数亿不同文化背景的消费人群」；并称「集团以 IP 为核心的商业生态系统正在逐渐成熟」。

消费品：手办/毛绒/MEGA/衍生品 + 饰品/家电/卡牌/积木服务与体验：城市乐园/甜品/主题展/旗舰店数字娱乐：电影/动画/游戏/绘本/授权

支撑层｜让多业态能共用一套底座

自有供应链工厂（2026H1 逐步投用）+ 海外合作基地；四大区域总部；2026 年 3 月设 CGO（文德一）专管「以 IP 为核心的集团化业务创新」，司德任唯一 COO 统管全球运营；IPO 募资用途变更，把「主题乐园、主题展览等 IP 商业化平台」纳入潜在投资范围。

组织双线：全球化（COO）× 集团化（CGO）未动用募资约 19.34 亿港元调整用途无银行借款，2026H1 现金 124.4 亿

王宁的比喻与筛选标准

  • 陆军＝线下门店；海军＝甜品、家电；空军＝电影、游戏（辐射更远）。原话：「理想状态陆海空军都强，但现在其实只有陆军比较强。」
  • 选品类标准：优先技术已成熟、不需底层技术迭代的品类，用 IP 赋能增值（小家电、饰品）；优先市场体量足够大的赛道；甜品是为配套线下乐园、做极致体验而布局。
  • 不做的事：沿袭别人的路。「迪士尼对 IP 的尊重与运营、LVMH 对品牌的打造值得学习，但必须走自己的路」；IP 更像「体育明星（梅西）」而非「电影明星（小李子）」——靠持续曝光而非叙事。
  • 对标 IP 平台：司德称长期研究迪士尼，希望通过产品、联名、内容、乐园、门店延长 IP 生命周期，最终拥有 5–10 个具备 LABUBU 长期潜力的 IP。

三、现在都已经做了什么

时间轴 + 三类结果分层
  • 2020–2022｜定战略、试内容
    IPO 定下全球化 + 集团化；内部把出海、游戏、乐园、内容与 IP 产品列为同等重要，并判断「游戏优先级高于动画」，当时明确「做大游戏，不指望它赚钱」。
  • 2023｜第一个实体业态
    9 月北京朝阳公园城市乐园开园，约 4 万㎡ 轻量化改造（约为北京环球影城 1%），开园首月游客破 10 万人次。
  • 2024｜重组板块 + 品类爆发
    年报正式划分三大板块；零售首次拆成手办/毛绒/MEGA/衍生品四品类，毛绒同比 +1289%、占比 21.7%；乐园运营首年实现盈利；6 月自研手游《梦想家园》上线。
  • 2025｜主业爆发、种子发芽
    营收 371.2 亿（+184.7%）、经调整净利 130.8 亿、毛利率 72.1%；海外占比 43.8%、全球 630 店；毛绒占比升至 50.4%，THE MONSTERS 141.6 亿占 38.1%；乐园客流 +70%；孵化 POP BAKERY、popop；LABUBU 登陆梅西百货花车。
  • 2026 H1｜主动降速、集团化提速
    3 月组织调整（CGO 专管集团化）+ 索尼影业 LABUBU 电影官宣；4 月乐园 1.5 期分区开放、IP 小家电首发；6 月 POP BAKERY 阿那亚首店、《梦想家园》停运公告；H1 营收 171.7 亿（+23.8%），经调整净利 51.6 亿（+9.5%），王宁定调「调整年」，宣布 20–50 亿回购。
  • 2026 H2｜场景矩阵收敛
    7 月乐园 1.5 期全面开放并二次提价、新加坡甜品店；8 月中期业绩会明确乐园二期概念设计、2027 启动建设；10/27 Q3 收益同比 −45%~−50%，电话会明确「短期不大幅增加内容预算」；10/31 北京合生汇 POP BAKERY 首店，与零售店、popop 组成「潮玩+饰品+甜品」矩阵；11/05 CLOT 联名麻将售罄。

✅ 已跑通 / 有数据支撑

  • 品类扩张：毛绒 21.7%→50.4%，是最成功的「集团化第一阶段」。
  • 城市乐园：首年盈利、客流 +70%、二次消费 >72%、园内衍生品约 6 倍店效，票价一年两涨仍有客流。
  • 甜品单店模型：阿那亚首月 >6 万人次、新加坡客单价 >50 新币（约 250 元）。
  • IP 小家电：5999 元限量冷藏箱开售即罄，验证 IP 溢价可平移到耐用品。

❌ 已收缩 / 明确失败

  • 游戏：《梦想家园》运营约两年停服。王宁：「电影和游戏都不够成功，我们也在反思……学费必须交。」
  • 内容自制能力：电影至今仍在剧本阶段，尚无任何上映时间表。
  • 外部 IP 收购：2025 年报以「优质 IP 收购机会有限」为由，把原定 IP 收购募资改投海外拓展，等于放弃买 IP、改为自己孵化 + 多业态变现。

⏳ 待验证 / 早期

  • popop 饰品、卡牌、积木、趣拍机：仅见门店/产品，无收入与复购数据。
  • 甜品可复制性：合生汇店被媒体指出产品与快闪/乐园高度重叠、动线窄、溢价偏高，复购机制未建立。
  • 家电耐用属性：功能、材质、售后、比价逻辑与潮玩完全不同，999–5999 元价格带能否持续存疑。
  • 第二座乐园 / 二期：仍在选址与概念设计，2027 才可能开工。

4.2 四个「克制」信号：集团化不会变成大跃进

① 内容预算：Q3 电话会明确短期不大幅增加，视项目进展再定；② 甜品：不追求开店数量，先打磨供应链与培训；③ 乐园：王宁称「不会以数量为目标」，先做好一个成熟样板再复制；④ 主业：不做大规模促销，库存从 7 月起掉头向下。叠加 2026 被定义为「经营调整年」、20–50 亿回购，可以判断：2026–2027 集团化的主基调是「低成本试错 + 能力补齐」，而不是「重资本押注」。

加速条件什么情况下会加大投入

  • 主业增速持续回落，需要新增长叙事（Q3 −45%~−50% 已构成压力）。
  • 某单店模型被验证可复制（乐园二期、甜品商场店、popop）。
  • 电影进入制作/上映周期，需要配套商品与乐园内容。
  • 账面现金 124.4 亿 + 无银行借款，试错弹药充足。

刹车条件什么情况下会收缩

  • 新业态复购不足、体验口碑反噬 IP（餐饮食安、家电售后）。
  • 库存周转继续恶化（123→约 201 天）、经营现金流转化下降。
  • 组织管理半径超负荷：王宁给 2025 年组织打 70 分、业绩 95 分。
  • 参考先例：游戏业务验证失败后直接停运，说明公司愿意止损。

5.4 对标迪士尼：利润池在体验，但代价是重资本

迪士尼 FY2025 收入 944.25 亿美元：娱乐 424.66 亿（45%）、体育 176.72 亿（19%）、体验 361.56 亿（38%）；分部运营利润分别为 46.74 / 28.82 / 99.95 亿美元，体验独占约 57%。代价是 2026 财年计划资本开支 90 亿美元，主要投向乐园扩建。

泡泡玛特当前是反向结构：99% 收入来自高毛利商品，几乎无体验收入，因而净利率（2025 约 35%）远高于迪士尼（约 13%）。集团化越成功，报表越像迪士尼 → 收入更稳、利润池更厚，但净利率与 ROE 会结构性下移。这是估值重估时必须同时计入的一体两面。

六、对整体布局的影响

结构、组织、风险分散、估值范式

结构：一维 → 三维

过去是「IP × 门店数」的一维扩张；现在变成 地域（20 国 / 630 店）× 品类（手办/毛绒/饰品/家电/食品）× 业态（零售/乐园/餐饮/内容/授权）。同一 IP 的变现次数增加，理论上抬升单 IP LTV。

组织：双线分立

COO 司德管全球运营与四大区域，CGO 文德一管集团化创新；2026 年重点补产品运营、供应链、物流、库存等「基本功」。代价是管理半径变长——王宁自评 2025 组织 70 分、业绩 95 分。

资本：从买 IP 到建平台

2025 年报把原定「收购受欢迎 IP」的募资改投海外拓展与营运资金，并把「主题乐园、主题展览等 IP 商业化平台」纳入潜在投资范围（未动用募资约 19.34 亿港元调整用途）。战略重心从「买资产」转向「自建变现场景」。

结论：集团化的分散效应目前主要体现在 IP 维度，且部分被品类集中抵消。真正能对冲周期的是「高频、低价、不可转卖」的体验消费与「近乎零边际成本」的授权收入，而这两块恰好是当前最弱的两块。

正面布局价值

  • 把「一次性交易」变「日常触点」：办公桌上的 1 亿只 LABUBU + 甜品/乐园/家电，持续加深 IP 认知。
  • 线下场景矩阵：合生汇「潮玩 + 饰品 + 甜品」同场联动，提升商场议价力与客单。
  • 轻量化乐园可复制：4 万㎡ 改造城市公园，投入远低于迪士尼级重资产，模型若跑通可复制到上海及海外。
  • 财务安全垫：2026H1 现金及等价物 124.4 亿、2025 年末资产负债率 29.4%、无银行借款，足以承担多年试错。

负面布局代价

  • SKU 与供应链复杂度：从玩具扩到食品、家电、饰品，冷链短保、食安、售后、比价都是新功课。
  • 品牌稀释：高频低价品类可能消耗稀缺感与溢价；媒体已指出甜品与快闪产品重叠、新鲜感易耗尽。
  • IP 权属风险：艺术家授权为「保底 + 分成」，合约到期谈判筹码在对方，多业态变现反而放大这一敞口（第三方观点）。
  • 能力错配：内容、餐饮、耐用品都不在原能力圈内，游戏停运已是先例。

6.2 估值范式：集团化真正想买的是「倍数」

市场当前按「爆款周期股」定价：2025 净利 127.8 亿，2026 年 8 月市值约 1984 亿港元，静态约 15x；Q3 后股价一度触及 123.8 港元。集团化的目标是把估值锚从「下一个爆款」换成「IP 组合的长久期现金流」——即迪士尼/三丽鸥式的平台倍数。但要拿到这个倍数，必须先交出可审计的证据：非商品收入单列且成规模、老 IP 跨周期稳定变现、授权费率可验证。在此之前，集团化更像是用主业现金流买入的一组实物期权。
