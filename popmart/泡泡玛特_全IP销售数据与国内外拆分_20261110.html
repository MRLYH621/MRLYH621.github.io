先说结论：三层数据，一层能拿、一层能拿、一层拿不到

① 按 IP 的收入：有，但只有 8–9 个头部 IP。财报把 90+ 个运营 IP 里的前 8 个单列，其余全部合并为「其他艺术家 IP」，无法逐个拆。

② 按国内外的收入：有，且细到「区域 × 渠道」。中国 / 亚太 / 美洲 / 欧洲及其他四区，另有线下门店、机器人商店、线上、批发的分区数据。

③ IP × 国内外的交叉数据：官方从未披露。没有任何一份财报或电话会给出「某 IP 在中国卖了多少、海外卖了多少」。市面上流传的分 IP 海外数字均为第三方推测，本表不收录。

最容易混淆的一个口径：「授权 IP」不是「IP 授权收入」

财报里的 授权 IP 33.82 亿（2025，占营收 9.1%）是把别人的 IP 授权进来做商品（迪士尼、皮克斯等联名产品）产生的商品销售收入；而把自有 IP 授权出去收的费叫「授权费及其他服务收入」，2025 仅 0.706 亿。它不在「按 IP 划分的收入」表里——那张表 100% 是商品销售收益；这笔钱计入损益表的「其他收入」附注（见附表 A），会计上不属于营业收入。两者方向相反，不可混用。这也是判断「集团化是否落地」的关键：泡泡玛特 99% 以上的收入仍来自自己卖货。

① 总盘怎么来的 可校验

  • 官方硬约束：2025H1 138.76 + 2025 全年 371.20 → 2025H2 = 232.44 亿（可精确相减）。2025Q3 是史上最高单季，券商（浦银等）估算 120–130 亿，按 2026Q1 公告 +75%~80% 与 H1 171.73 亿倒推的季度序列给出约 116 亿，两者接近。
  • Q3 总盘：基数 × (1 − 官方降幅)。中性 120 × 52.5% = 63.0 亿，与华福证券「测算 26Q3 单季约 63 亿」独立吻合；区间 58–71.5 亿。
  • 区域自洽校验：要让四个分区降幅的中值加权后落在官方整体 −45%~−50% 内，2025Q3 的区域结构需大致为中国约 48%、海外约 52%（亚太 22% / 美洲 24% / 欧洲 6%），加权结果 −48.6%。海外占比高于 2025 全年的 43.8%，与「峰值季由美洲、亚太线上爆发拉动」的叙事方向一致。这是一致性检验，不是官方区域数据。
  • 全年交叉验证：中性全年 312.7 亿（−15.8%），对照华福预估 310 亿 / −16.5%、另一研报「至少 300 亿」，量级一致。

② 各 IP 怎么分 · 误差在哪 务必读

  • 份额法：以 2026H1 官方各 IP 金额为结构基准；只调整 THE MONSTERS 的占比（默认 26.0% → 21%，理由是 Q3 跌幅主要来自海外线上、而该 IP 在海外线上权重最高），其余 9 项按 H1 相对权重等比填满剩余份额。
  • 这是中性假设，不是预测：它等价于「第二梯队既没有单独爆发、也没有单独失速」。若星星人在 Q3 承接超预期，实际值会高于表中数字；若毛绒品类整体退潮快于手办，则低于。
  • 方向性线索：证券时报引述「Q3 亚太前六大 IP 贡献超六成业绩」；高盛渠道跟踪称 9 月新品亮点转向 Zsiga 等手办、小 IP 毛绒偏疲态；管理层称星星人是海外营销重点。均支持「TM 占比继续降、第二梯队相对承接」，但都不给金额。
  • 误差量级：总盘误差约 ±10%（基数与降幅区间），单 IP 结构误差可达 ±30% 以上。这张表的用途是看结构迁移的方向与相对量级，不是给出可引用的季度财报数字。真正验证要等 2027-03 的 2026 年报。

为什么拿不到，以及可以退而求其次怎么做

财报按「IP」「区域」「品类」「渠道」四张表分别披露，彼此不交叉。管理层也从未在电话会给出分 IP 的区域数字。若要近似，只能用第三方电商/社媒数据（各站点销量、Google Trends、二手溢价）做代理指标，但这类数据无法覆盖占大头的线下门店，误差不可控，本报告不采用。

可用的替代观察：区域毛利率差异（2025 海外商品单价更高，推动整体毛利率 +3.5pct）、分区域线上线下增速差（表 5），以及头部 IP 占比变化与区域增速的时序对照——2025 美洲爆发与 THE MONSTERS 占比 38.1% 同期，2026H1 美洲 −16.5% 与 THE MONSTERS −7.5% 同期，方向一致但无法证明因果。

五、口径与来源

用数前必读

七条防踩坑提示

  • 币种：本表全部为人民币。部分第三方数据库（港股财务指标）用港元列示，数字约大 10%（如 THE MONSTERS 2025 显示 156.78「港元」而非 141.61 人民币），切勿混用。
  • 期间：2026H1「11 个 IP 过亿」是半年口径，与 2025 全年「17 个过亿」不可直接比较；2025H1 为 13 个。
  • 重分类：2025 年报重述 2024——新增单列星星人 1.21 亿、把 Zsiga 2.45 亿并入「其他艺术家 IP」，导致该聚合项 2024 数从 14.09 亿变为 15.33 亿。
  • 区域口径变更：2024 年报用「中国内地 / 港澳台及海外」旧口径，2025 年报改四区口径并重述对比数；表 4 的 2024 与 2025H1 分区值为按官方增速反推的约数。
  • 「过亿」指收入过 1 亿元人民币的艺术家 IP，不含授权 IP 与外采；财报只披露数量、不披露这 17 个分别是谁。
  • 表外科目：「授权费及其他服务收入」与「政府补贴」计入损益表「其他收入」，不属于营业收入；表 1–3 只拆收益，故不含这两项。原先把 0.71 亿写作「占营收 0.19%」只是量级类比，会计占比不成立，详见附表 A。
  • 2026Q3 不是财报：10-27 的「最新业务状况」是自愿性季度更新，只有同比区间、无绝对额、无利润、无按 IP 拆分，且未经审核。第一节琥珀标签里的 2026Q3E / 2026 全年E 全部是本报告的模型推演（份额法 + 券商基数估算），与表 1–3 的官方原表性质不同，禁止混用或当作公司披露引用。公司历来不披露单季按 IP 拆分，2027-03 的 2026 年报也只会给全年口径；因此推演里 Q3 单季的分 IP 数字永远无法被直接验证，能被验证的只有全年各 IP 合计。
