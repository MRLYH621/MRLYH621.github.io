一、结论先行：护城河不在某个 IP，在这套"操作系统"

先给答案，再拆解

① 怎么解决"艺术家签约"这道护城河？

泡泡玛特用四类分层合作把散落全球的创作者聚成"可复制的 IP 供给池"：外部独占授权（早期形态，如星星人/CRYBABY 成长期）、买断永久自有（如 Molly/DIMOO/SKULLPANDA，且 Labubu/THE MONSTERS 经收购后也已落入此档）、内部 PDC 孵化（如小野/Zsiga）、新锐阶梯合作（如 PEACH RIOT）。底层是"创作归艺术家、商业运营归泡泡玛特"的权利切割 + 利益绑定 + 矩阵分散。

② 跳槽咋办？—— 分两类，都已"锁死"

买断 / PDC 类：IP 著作权 100% 归公司，人走 IP 不走，可换设计师续作（Molly 即例；Labubu 经收购后同属此类，无续约风险）。外部授权类（如星星人/CRYBABY 成长期、龙家升早期 2019–收购前）：公司仍握商标、全球渠道、产品库存、用户基础，即便极端不续约也可继续卖、继续做、继续授权；原作者也因商标/外观专利在手，无法在中国及全球大部分地区卖原始形象。头部更被股权深度绑定（王信明持约 1.49%≈46 亿港元，离场=放弃巨额增值）。

③ 这些 IP 现在"是授权的，还是已经属于泡泡玛特了"？—— 混合

早期头部（Molly/DIMOO/SKULLPANDA）已买断，著作权 100% 归公司；最火的 Labubu（THE MONSTERS）也已"完全收购"，著作权永久归公司（王宁 2025 股东会原话；龙家升保留署名权与递减分成权，无续约风险）；内部 PDC（小野等）从出生就是公司的。即"头部 IP 绝大部分本来就是泡泡玛特的"——原报告所谓"最赚钱的是长租 + 商标锁定"经核验为过时表述，已更正。

二、四种合作模式：把"签约"做成可复制的流水线

来源 / 机制 / 版权 / 代表 IP

① 外部独占授权 · 锁住经营权（Labubu 已被收购，见更正）

艺术家保留著作权、署名权、创作自由；泡泡玛特拿到全球独家生产/销售/联名/二次授权/商标注册/维权全链条权利，长约锁定。最特别之处：锁定的是"经营权"，不是"著作权"。

代表：星星人 / CRYBABY（成长期）长约锁定经营权销售分成（估 8%–15% 阶梯）后续可买断收编

⚠️ 更正：原以此档举例的 Labubu（THE MONSTERS） 经王宁 2025 股东会"完全收购"表态 + 段永平 2026-08 核验，著作权现已归属泡泡玛特（永久自有），已从本档滑入"② 买断永久自有"；原"签至 2030-04-30"为 2019 年初始框架，已被收购取代，非续约风险。

② 买断永久自有 · 一次性把 IP 收归公司

外部艺术家签约 → 版权一次性买断 → 作者拿永久销售分成，个别叠加股权。IP 100% 归公司，零续约风险、永久可控。

代表：MOLLY（王信明）DIMOO（Ayan 邓瑞雪）SKULLPANDA（熊喵）Molly 2019 买断 + 授 2% 股权

③ 内部 PDC 孵化 · 把个人变成公司能力

2021 年成立设计师中心 PDC，员工制：公司出选题/资源/流量/全球运营，设计师拿薪资+奖金+爆款分成，IP 著作权、商标按劳动合同 100% 归属公司。没有解约/续约风险，IP 不因个人走掉而断档。

代表：HIRONO 小野（Lang）Zsiga（吾丹丹）小甜豆 / PINO JELLY / Yuki近年顶部 IP 接力靠此引擎

④ 新锐阶梯合作 · 随成熟度加深的滑动频谱

不是固定模板，而是随 IP 成熟度变化的路径：测试期 1–3 年短约试水 → 成长期 3–5 年买断式授权 → 成熟期永久买断或收编进 PDC。"创意到货架"业内测最快约半年，跨国别同样适用。

代表：CRYBABY（泰国 Molly）PEACH RIOT（首个美国原创 IP）收编与签约边界模糊化试错成本最低
注：四类边界并非铁板——PDC 内部同样吸纳外部人才，买断与自有之间无硬界线；"筛人"和"建墙"其实是同一件事。外部独占授权与买断两类路径，招股书与华创/浙商证券复盘可印证；阶梯合作与最新案例为公开报道梳理。

四、护城河机制：段永平列进"四大壁垒"的艺术家共生网络

为什么别人抄不走

段永平总结的四大壁垒 段永平公开表述

  • ① 品牌与用户心智：钱能砸流量，砸不出粉丝情感认同。
  • ② 艺术家共生网络：签约/扶持全球艺术家，形成 IP 供给池；大厂能高薪雇设计师，却难复制"发掘+激励艺术家"的体系。
  • ③ 全球线下渠道网络：门店+机器人商店既是渠道也是广告，点位与运营需时间沉淀。
  • ④ 创始人+团队组织能力：产品、供应链、品质、全球运营整套能力。

原话："你可以复制其中某一个环节，但复制不了整套互相强化的系统。这些壁垒不能保证潮玩永远有人喜欢，但可以让喜欢潮玩的人持续关注泡泡玛特。"

王宁的"唱片公司"比喻 王宁

王宁把泡泡玛特比作唱片公司：公司不发明歌手，而是发掘有潜力的艺术家，深度绑定，共同运营 IP。卖的不是塑料玩偶，是情绪 IP 的"全球发行+周边"。

落到操作层，是一套闭环操作系统：

  • 发掘：20+ 人团队，350+ 艺术家紧密联系，靠 BTS/PTS 潮玩展用销量与流量"赛马"。
  • 孵化：PDC 内部标准化产出（小野/Zsiga），把"个人"变"能力"。
  • 工业化：供应链+设计把形象快速做成可陈列、可挂、可换装的商品。
  • 渠道+社群：全球门店、会员（2025 超 1 亿）、复购 55.7% 形成反馈飞轮。

关键判断：护城河防的是"人出走"，安顿的也是"人"

头部作者一个留著作权+分成进账，一个靠买断拿财务自由+永久分成；PDC 设计师有工资、资源、爆款奖金；新人从低门槛试水起步。四种契约预防风险，安顿的却是创作热情——这才让"创意到货架"半年压完、别人难以复制。壁垒保护城池，城池能建多大，取决于系统能不能持续孵化下一个 Labubu。

五、跳槽怎么办：三种情形推演

极端情形下的真实边界

A · 买断 / PDC 类艺术家离开

  • 法律：IP 100% 归公司，人无权带走，可换设计师续作。
  • 先例：Molly 王信明已不再量产新设计，Molly 仍稳定贡献（2025 收入 28.97 亿，+38.4%）。
  • 商业风险：失"灵魂"/设计水准，粉丝可能不买账——但 IP 资产不流失。

B · 外部授权类 IP（如星星人/CRYBABY 成长期）不续约

  • 不能做：用原始底稿开新模具、出"原版新形象"（仅限未买断的授权类 IP）。
  • 仍能做：卖库存（清货期约 6 月）、用商标、用已开发二次创作、用渠道库存、继续授权。
  • 原作者也受限：商标/外观专利在手，其本人无法在中国及全球大部分地区售原始形象。
  • Labubu 已不适用此情形：其著作权已归公司（收购），不存在不续约风险。

C · 被竞品高薪挖角

  • 头部已股权绑定：王信明持约 1.49%（≈2000 万股，按市值约 46 亿港元），离场=放弃巨额增值。
  • 新锐靠 PDC 员工制：天然无解约风险。
  • 深度利益共同体：市场推测泡泡玛特持龙家升 how2work 工作室 25% 股权（"半买断"，待公司确认）。

王宁在 2025 年股东会"锁死"风险（原话，含后续修正）

"THE MONSTERS 是长期独家授权，已签到 2030，全球独家。我们和龙家升关系非常好，是深度伙伴、长期共建。就算极端情况——他到期不续约，我们也能继续卖、继续做、继续授权 Labubu。商标、全球渠道、产品库存、用户基础全在我们手里。他自己在中国也卖不了，离开我们他也做不大。不是他绑着我们，是互相深度绑定。"

⚠️ 同一场股东会另一组在场股东记录显示，王宁更晚近的表述为"the monsters 我们现在已经完全收购了"；段永平 2026-08-27 亦核验"labubu 版权已经属于泡泡玛特了，根本不存在续签问题"。即上段"签至 2030"为 2019 年初始授权框架，其后已被收购取代——"极端不续约"的边界情形对 Labubu 已不再适用，著作权风险实质性消除。

七、对投资的含义与跟踪信号

护城河 vs 必须盯住的风险

正面：护城河真实且结构性 支撑估值

  • 不是靠单一爆款赌运气，是持续产出 IP 的系统；LABUBU 只是系统产物。
  • 自有 / PDC 占比上升稀释关键人风险：小野、星星人、Zsiga 多来自内部引擎。
  • "权利切割 + 商标在手"使极端不续约情形可控而非灭顶。
  • 财务安全垫厚（净现金、无息负债），试错成本低。

风险：必须盯住的硬信号 折价因子

  • Labubu 占 2025 营收 38.1%，但经收购后已为永久自有 IP，无续约风险——原"2030 续约是估值最需打折的变量"已更正移除，属净正面修正。
  • "商品先行"IP 跨代际长青尚未被验证（对比米老鼠/Hello Kitty 几十年）。
  • 艺术家流失率/签约数未披露，外部难以实时量化人才护城河健康度。
  • 设计/授权费率长期 1%–3%，若头部重谈跳升将侵蚀毛利。

给持仓者的四个跟踪信号

① Labubu 收购后的整合与龙家升分成权条款（确认永久自有、分成随创作递减）；② PDC / 内部孵化 IP 收入占比（上升=风险下降）；③ 非 Labubu IP 在欧美非华人市场的独立复购（验证全球化非华人基本盘）；④ 艺术家年签约数 vs 流失数及设计授权费率是否跳升。出现"核心艺术家跑光/费率跳升/外部授权 IP 占比异常扩大"任一，长期故事需打折。
