泡泡玛特 vs 迪士尼·三丽鸥

IP 数量与授权费（royalty）对比 · 数据截至 2026-11-10 · 汇率 USD/CNY≈7.3，JPY/CNY≈20.9

结论先行 TL;DR

① IP 数量：迪士尼 15+ 主流 franchise + 数千角色；三丽鸥 450+ 原创角色；泡泡玛特 17 个艺术家 IP（年收破亿）+ 授权 IP 若干。

② 授权费收入（royalty，实收）：迪士尼约 276 亿 RMB（FY24 商品 IP 授权）、三丽鸥约 34 亿 RMB（FY25 版权收入）、泡泡玛特仅 0.706 亿 RMB（2025）。

③ 本质差异：迪士尼/三丽鸥是"别人生产、我收租"的纯授权商；泡泡玛特是"自己造、自己卖"的 DTC 产品公司。授权费少 ≠ 弱，反而是被低估的期权。

④ 潜力：若把头部 IP 像三丽鸥那样开放第三方授权， royalty 线有 约 48 倍（对标三丽鸥） 的空间；但更现实的近景驱动是"集团化"（乐园/影视/甜品/饰品/家电）的多品类延伸。

三、为什么泡泡玛特"授权费"这么少？

不是能力问题，是商业模式根本不同：

  • 迪士尼 / 三丽鸥：纯 IP 授权平台。自己很少生产，把 IP 租给 H&M、乐高、万代等第三方制造销售，靠抽成（royalty）赚钱。三丽鸥版权收入占营收近一半。
  • 泡泡玛特：DTC 产品公司。自己设计、自己生产、自己开店卖（盲盒、毛绒）。2025 年艺术家 IP 产品销售收入 334 亿——它把 IP 价值通过"卖货"而非"收租"吃掉了。
  • 双向授权：泡泡玛特既"收"也"付"。收：对外授权 IP 得 0.7 亿；付：为外采联名 IP（如哈利波特）付授权费，2026H1 支出 3.762 亿。当前是净付出方。
一句话：迪士尼/三丽鸥的"授权费"是主营业务；泡泡玛特的"授权费"目前只是主营业务（卖货）之外的一小块补充。

四、潜力有多大

1）纯 royalty 线的上行期权（10–50 倍）

  • 若泡泡玛特把 Labubu / Molly / 星星人 像三丽鸥那样开放给服装、食品、家居、3C 等第三方授权，royalty 从 0.7 亿 → 对标三丽鸥 ≈ 34 亿（约 48 倍） 是理论天花板。
  • 支撑：IP 已具全球心智（Labubu 破圈）、会员破 1 亿、复购 51.6%，第三方授权的基础已具备。2026H1 royalty 已 +135%，起步快。

2）更现实的近景驱动：集团化（多品类自有延伸）

  • 泡泡玛特选的"集团化"是自己下场做乐园、影视、游戏、甜品、饰品、小家电，而非纯收租。这块是"卖服务/体验"而非"收授权费"，价值更大但更重。
  • 2026H1 中国区"批发及其他"含乐园/甜品/饰品已快速放量（同比 +111.7%），是可验证的增量。

3）结构性护城河：多 IP 组合对冲

  • 2026H1 LABUBU 收入 -7.5%、MOLLY -33.6%，但星星人 +580.6%、CRYBABY/DIMOO/SKULLPANDA 均双位数增长——多 IP 矩阵把单 IP 波动熨平，这是三丽鸥验证过、泡泡玛特正在复刻的逻辑。
估值含义：泡泡玛特今天的价值不在 royalty（占比 <0.2%），而在"IP 组合 + DTC + 集团化延伸"的复合体。royalty 线是 5–10 年维度的看涨期权；若市场开始按"中国版三丽鸥/迪士尼平台"重估，上行不封顶，但前提是 IP 寿命被长期验证、且授权/延伸真正规模化。
